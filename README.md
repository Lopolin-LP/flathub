# sm64coopdx
## Quick Info
- Mods and configs are found in `~/.var/app/com.sm64coopdx.sm64coopdx/data/sm64coopdx/`

## Troubleshooting
### Invalid ROM
- File system access issues. If that file is not in the downloads folder, sm64 can't access it. Grant more access via flatseal if needed.
